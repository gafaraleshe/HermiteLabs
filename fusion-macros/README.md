# fusion-macros

Stage 1 — **Hermite Motion**. Lua scripts and Fusion `.setting` files (motion presets, easing macros, speed-ramp tooling), packaged into the installable `.drfx`.

No dependency on `backend/`, `app/`, or anything network-facing — this stage must work standalone inside Resolve. See [HERMITE-PLAN.md §2](../HERMITE-PLAN.md#2-feature-list--hermite-motion-stage-1).
