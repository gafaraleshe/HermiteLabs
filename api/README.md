# api

Stage 4 — **Hermite API** (enterprise). The cloud-hosted, paid API: same `core/` logic as `backend/`, different host — API key auth, Polar.sh billing, rate limiting, and Composio toolkit registration for MCP agent access.

Never touches Resolve; pure cloud processing on uploaded data, positioned as a separate, explicitly-opt-in product line from the on-device story. See [HERMITE-PLAN.md §4a](../HERMITE-PLAN.md#4a-feature-list--hermite-api-stage-4-enterprise).
